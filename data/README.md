# Dataset Documentation

## Overview

PCA-Triage evaluates on 7 benchmark datasets. Raw data files are not included in the repository due to size and licensing. Follow the instructions below to download each dataset.

## Download Instructions

Run `bash data/download.sh` for guided download instructions, or follow manually:

### 1. TEP (Tennessee Eastman Process)
- **Source:** [Harvard Dataverse](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/6C3JR1)
- **Files:** `TEP_FaultFree_Training.RData`, `TEP_Faulty_Training.RData`
- **Format:** R DataFrames (loaded via `pyreadr`)
- **Place in:** `data/raw/`
- **Channels:** 52 (41 xmeas + 11 xmv)
- **Samples:** ~250K

### 2. SKAB (Skoltech Anomaly Benchmark)
- **Source:** [GitHub](https://github.com/waico/SKAB)
- **Download:** `git clone https://github.com/waico/SKAB.git data/raw/skab_repo`
- **Format:** CSV files with `;` separator
- **Channels:** 8
- **Samples:** ~47K

### 3. SMD (Server Machine Dataset)
- **Source:** [OmniAnomaly GitHub](https://github.com/NetManAIOps/OmniAnomaly)
- **Preprocessing:** Concatenate machine files, add `anomaly` column
- **Output:** `data/raw/smd_combined.csv`
- **Channels:** 38
- **Samples:** ~388K

### 4. MSL (Mars Science Laboratory)
- **Source:** [telemanom GitHub](https://github.com/khundman/telemanom)
- **Preprocessing:** Combine train/test NPY files into CSV with `anomaly` column
- **Output:** `data/raw/msl_combined.csv`
- **Channels:** 55
- **Samples:** ~132K

### 5. PSM (Pooled Server Metrics)
- **Source:** [eBay RANSynCoders GitHub](https://github.com/eBay/RANSynCoders)
- **Preprocessing:** Combine train/test CSV files, add `anomaly` column
- **Output:** `data/raw/psm_combined.csv`
- **Channels:** 25
- **Samples:** ~220K

### 6. HAI (HIL-based Augmented ICS)
- **Source:** [GitHub](https://github.com/icsdataset/hai)
- **Preprocessing:** Combine CSV files, exclude `time` column, add `anomaly` column
- **Output:** `data/raw/hai_combined.csv`
- **Channels:** 82
- **Samples:** ~259K

### 7. SWaT (Synthetic)
- **No download needed** — generated by `src/utils/synthetic_datasets.py`
- Calibrated to match iTrust SWaT testbed properties (51 channels, 12% anomaly rate)

## Verification

After downloading, verify all datasets:

```bash
python -c "
from src.utils import list_datasets, get_dataset
for name in list_datasets():
    try:
        X, y, _, _, cols, _ = get_dataset(name)
        print(f'{name:6s}: {len(cols)} channels, {X.shape[0]} train samples')
    except Exception as e:
        print(f'{name:6s}: NOT AVAILABLE — {e}')
"
```
